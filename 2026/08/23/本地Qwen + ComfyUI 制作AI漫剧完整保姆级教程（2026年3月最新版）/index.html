本地Qwen + ComfyUI 制作AI漫剧完整保姆级教程（2026年3月最新版）

发表于2026-08-23|更新于2026-08-23
|浏览量:

这个组合是 目前零成本、无限生成、角色一致性最强的本地方案 ！ Qwen（本地大模型）负责 写剧本 + 自动拆分镜 + 生成提示词 ；ComfyUI负责 图像生成 + 角色一致性 + 动态视频 。 适合新手/日更党，低配8GB显存就能跑（推荐12GB+更流畅）。全流程免费、无网络依赖、隐私安全。模型+：工作流： https://pan.quark.cn/s/efc430e1996d

一、硬件要求（必看）

  • GPU ：NVIDIA 8GB显存起步（RTX 3060 12GB最稳），AMD/Intel也可（需ROCm/OneAPI）。
  • 内存 ：16GB+ RAM（32GB最佳）。
  • 硬盘 ：SSD 50GB+ 空闲空间。
  • 系统 ：Windows 10/11（推荐）或Linux/Mac。

二、第一步：安装本地Qwen（写剧本神器）

  1. 下载 Ollama （最简单本地LLM工具）： 官网 https://ollama.com 下载安装（几分钟搞定）。
  2. 打开命令提示符（Win+R输入cmd），运行命令拉取模型：
    text

或轻量版：

text

  • 测试：运行 ollama run qwen3.5:32b，输入“写一个3分钟校园甜宠漫剧大纲”测试即可。

作用 ：用它写完整分镜剧本（镜号 + 画面描述 + 台词 + 提示词），比在线豆包更稳定、无额度限制。

三、第二步：安装ComfyUI（图像/视频生成核心）

  1. 下载 ComfyUI Portable （最方便）： GitHub: https://github.com/comfyanonymous/ComfyUI 下载最新Portable版，解压即可运行 run_nvidia_gpu.bat（N卡）。
  2. 第一次运行会自动下载基础模型（等10-20分钟）。

四、第三步：安装必备自定义节点（关键！）

在ComfyUI文件夹里打开终端，运行以下命令（一次性安装）：

text

重启ComfyUI后，Manager（自定义节点管理器）里搜索安装：

  • ComfyUI-Qwen 或 Qwen-AIO大合集 （2026最强漫剧节点）
  • IPAdapter + ControlNet （角色一致性）
  • Wan2.2 或 AnimateDiff （图生视频）

推荐工作流下载 （2026最新）：

  • B站搜“ComfyUI Qwen-AIO 漫剧” 或 “QwenImageEdit-2511 整合包”
  • YouTube搜“ComfyUI QwenMultiAngle 一张图生成多视角”
  • 常用工作流可在 https://www.comfy.org/zh/workflows/ 搜索 “Qwen Image 2512” / “Qwen-AIO”

五、完整制作AI漫剧流程（一步一步来）

第1步：Qwen写分镜剧本 （Ollama里） 复制这个Prompt模板：

text

第2步：ComfyUI生成角色一致性 （固定人设）

  • 加载 Qwen-AIO 或 IPAdapter 工作流
  • 上传2-4张参考图（正面/侧面/表情）
  • 一键生成多角度、多场景角色图（QwenImageEdit节点超强）

第3步：批量生成分镜画面

  • 把Qwen输出的分镜描述复制到ComfyUI的提示词节点
  • 用 Qwen Image 2512 或 Flux + IPAdapter 生成每镜高清图
  • 一键多图批量生成（支持连续性分镜）

第4步：生成动态视频

  • 加载 Wan2.2 或 AnimateDiff 工作流
  • 输入首尾帧（前面生成的图）+ 运动提示（如“缓慢转身、眼神温柔”）
  • 生成1-3秒短视频片段（角色动作自然）

第5步：后期合成

  • 导出所有视频片段到剪映（CapCut）
  • 加字幕、BGM、转场、音效（Qwen3-TTS可本地配音）
  • 导出1080×1920竖屏MP4

一集3分钟漫剧 ：全流程1-2小时（熟练后更快）。

六、常见问题 & 优化Tips

  • 角色崩坏 ：多用IPAdapter + FaceID + ControlNet Pose（2026最稳方案）。
  • 显存不够 ：用GGUF量化模型 + 8G显存工作流（Qwen-AIO专为低配优化）。
  • 速度慢 ：开启ComfyUI的“–force-fp16”启动参数。
  • 想更自动 ：用ComfyUI的Ollama节点直接把Qwen写好的分镜自动喂给图像节点（IF_AI_tools实现一键流水线）。模型+：工作流： https://pan.quark.cn/s/efc430e1996d
