Spring AI Redis向量存储依赖解析

发表于2026-05-15|更新于2026-05-18|博客
|浏览量:

该依赖 spring-ai-starter-vector-store-redis 是 Spring AI 项目为 Redis 提供的向量存储（Vector Store）启动器，用于在 Spring Boot 应用中快速集成 Redis 作为向量数据库，实现语义搜索、推荐系统等基于向量相似度的功能。

1. 什么是 Spring AI Vector Store？

Spring AI 是 Spring 生态系统中的 AI 工程化框架，它抽象了与 AI 模型（如 OpenAI、Hugging Face）和向量数据库的交互。
Vector Store（向量存储）是其中用于存储和检索嵌入向量（Embeddings）的组件。通常流程：

  • 将文本、图片等数据通过嵌入模型转换为向量。
  • 将向量存入 Vector Store。
  • 运行时将查询文本转为向量，并在 Vector Store 中进行相似性搜索，找到最相关的记录。

2. Redis 作为向量存储

Redis 从 6.x 版本开始，通过 RediSearch 模块支持向量搜索功能。
Spring AI 对 Redis 的支持依赖 Redis Stack（包含 RediSearch 和 RedisJSON 模块）或独立启用了 RediSearch 的 Redis 实例。它提供以下能力：

  • 自动创建向量索引。
  • 支持多种相似度算法（如 L2 欧氏距离、内积、余弦相似度）。
  • 与 Spring AI 的 Document 抽象无缝集成。

6. 注意事项

  • Redis 版本要求：必须使用包含 RediSearch 模块的 Redis（如 Redis Stack 6.2+）。可通过 redis-cli MODULE LIST 检查是否已加载 search 模块。
  • 索引管理：initialize-schema: true 会在启动时自动创建索引，但生产环境建议关闭，手动通过 Redis CLI 或迁移工具管理索引，避免意外覆盖。
  • 性能调优：向量维度（默认 1536，OpenAI 嵌入维度）需与嵌入模型输出一致，可通过 spring.ai.vectorstore.redis.dimension 配置。
  • 事务性：RedisVectorStore 不支持 ACID 事务，但保证了原子性操作。
