Ollama向量模型推荐

发表于2026-05-15|更新于2026-05-18|博客
|浏览量:

Ollama 支持很多优秀的开源向量模型，为了帮你快速找到合适的，我整理了一份推荐清单，按使用场景和特点分了类，并附上了关键参数，方便你对比选择。

🔍 Ollama 向量模型推荐清单

🌟 通用与高性能

  • nomic-embed-text：768 维度, 8192 tokens。全能选手，性价比高，在语义搜索、文本相似度任务上表现均衡。
    ollama pull nomic-embed-text
  • mxbai-embed-large：1024 维度, 512 tokens。高维稠密向量，适合对向量维度有较高要求的场景。
    ollama pull mxbai-embed-large

💪 强大与多语言

  • bge-large：1024 维度, 512 tokens。英文检索质量高，在追求极致英文任务效果时可以考虑。
    ollama pull bge-large
  • bge-m3：1024 维度, 8192 tokens。多语言与多功能，BGE系列新作，支持多语言、多粒度、多功能。
    ollama pull bge-m3
  • multilingual-e5-large：768 维度, 512 tokens。多语言之王，覆盖100+语言，如果你的数据是多语混合的，选它准没错。
    ollama pull zylonai/multilingual-e5-large

🚀 轻量高效与中文优化

  • all-minilm：384 维度, 512 tokens。轻量级冠军，速度最快，适合资源有限或对实时性要求极高的应用。
    ollama pull all-minilm
  • shaw/dmeta-embedding-zh：约 400M 参数。中文场景首选，专为中文优化，在语义检索、RAG场景中表现出色。
    ollama pull shaw/dmeta-embedding-zh

✨ 前沿与多模态

  • qwen3-embedding：32-1024 (可变) 维度, 32K tokens。全能灵活，上下文窗口巨大，维度可变，支持多语言。
    ollama pull qwen3-embedding:0.6b
  • embeddinggemma：128-768 (可变) 维度, 2K tokens。资源友好，Google出品，在MTEB榜单上表现优异，且对硬件要求不高。
    ollama pull embeddinggemma:300m
  • Qwen3-VL-Embedding：64-2048 (可变) 维度, 32K tokens。多模态能力，不仅能处理文本，还能理解图像和视频，适合多模态检索。
    ollama pull MedAIBase/Qwen3-VL-Embedding:2b-fp16

💡 如何使用与选择建议

选定模型后，用 ollama pull <模型名> 下载即可。使用时，可以通过 Ollama 的 HTTP API 或各种框架（如 LlamaIndex、Spring AI）来生成嵌入向量。

  • 如果你是新手：从 nomic-embed-text 开始，它最不容易出错。
  • 如果你的数据主要是中文：强烈推荐 shaw/dmeta-embedding-zh。
  • 如果你需要处理多种语言：multilingual-e5-large 是你的不二之选。
  • 如果你在搭建一个极速响应的应用：all-minilm 可以满足你的需求。
  • 如果你想尝鲜，处理图文混合内容：试试 Qwen3-VL-Embedding。

你是主要处理中文场景，还是需要多语言支持？告诉我你的具体用例，我可以帮你锁定最合适的那一款。
