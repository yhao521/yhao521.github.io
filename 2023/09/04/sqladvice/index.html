其他问题说明：

-bash: locate: 未找到命令

原因：CentOS7默认没有安装该命令

解决方案：

1、安装”locate”命令 sudo yum install -y mlocate

2、执行完，mlocate已安装完成。接下来需更新后台数据库，输入命令：

sudo updatedb。

这里需要注意一点：如果没有updatedb更新后台数据库，直接输入查找命令：locate，还是未能找到命令。原因是Linux不是实时更新它的后台数据库，所以我们并不能马上执行。

3、运行“locate inittab”（必须安装完，并执行updatedb之后执行此命令）
