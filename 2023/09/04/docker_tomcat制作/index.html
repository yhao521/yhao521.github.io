tomcat镜像制作

  1. 镜像构建
    使用3中构建的程序包新建构建申请：
    编写Dockerfile：

        FROM 10.142.233.62:8021/m2m_dev/ketty:1.1.13-20170810-1
    ADD apache-tomcat-8.0.46.tar.gz /root
    RUN chmod +x /root/apache-tomcat-8.0.46/bin/*.sh
    ADD lbptest-spring.war /root
    RUN mkdir -p /root/webapps/lbptest-spring
    RUN unzip /root/lbptest-spring.war -d /root/webapps/lbptest-spring
    RUN rm /root/lbptest-spring.war
    CMD ["/root/apache-tomcat-8.0.46/bin/catalina.sh", "run"]

添加tomcat安装包自定义文件：
apache-tomcat-8.0.46.tar.gz
这里使用tomcat作为部署环境，需要添加tomcat安装包作为自定义文件，这里以 apache-
tomcat-8.0.46.tar.gz 为例

  1. 镜像发布
    发布4中构建的镜像：

5.1 上传配置文件
文件名称 替换路径

server.xml /root/apache-tomcat-8.0.46/conf

编写server.xml，配置启动端口和部署context

...
<!-- 指定http端口 -->
<Connector port="8777" protocol="HTTP/1.1"
connectionTimeout="20000"
redirectPort="8443" />
...
<Host name="localhost" appBase="webapps"
unpackWARs="true" autoDeploy="false">
<!-- SingleSignOn valve, share authentication between web applications
Documentation at: /docs/config/valve.html -->
<!--
<Valve className="org.apache.catalina.authenticator.SingleSignOn" />
-->
<!-- Access log processes all example.
Documentation at: /docs/config/valve.html
Note: The pattern used is equivalent to using pattern="common" -->
<Valve className="org.apache.catalina.valves.AccessLogValve" directory="logs"
prefix="localhost_access_log" suffix=".txt"
pattern="%h %l %u %t &quot;%r&quot; %s %b" />
<!-- 配置lbptest-spring应用 -->
<Context docBase="/root/webapps/lbptest-spring" path="" />
</Host>

5.2 新增自定义环境变量
键 值

ZK_CONNECT_STRING 10.142.233.80:8181
SERVICE_PORT 8777

5.3 发布镜像
发布镜像，并查看结果

docker run -d -p 80:80 -p 443:443 –name myjenkins-2 -v /home/yhao521/logs:/root/jenkins/tomcat8-8080/logs 55f1296cbc26

https访问

生成证书：

keytool -genkeypair -alias "tomcat" -keyalg "RSA" -keystore "test.keystore"

tomcat-8.5配置(增加，与tomcat7配置不同)

<Connector port="443" protocol="org.apache.coyote.http11.Http11Nio2Protocol" maxThreads="150" SSLEnabled="true" scheme="https" secure="true">
    <SSLHostConfig>
        <Certificate certificateKeystoreFile="conf/test.keystore" type="RSA"  certificateKeystorePassword="123456" />
    </SSLHostConfig>
</Connector>
