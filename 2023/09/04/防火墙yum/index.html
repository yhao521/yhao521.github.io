entOS 7.0默认使用的是firewall作为防火墙

查看防火墙状态

firewall-cmd –state

停止firewall

systemctl stop firewalld.service

禁止firewall开机启动

systemctl disable firewalld.service

转自：CentOS 6和CentOS 7防火墙的关闭

关闭selinux
进入到/etc/selinux/config文件

vi /etc/selinux/config

将SELINUX=enforcing改为SELINUX=disabled

超简单CentOS7 配置阿里云yum源

########################################################################################
1、打开centos的yum文件夹

输入命令cd  /etc/yum.repos.d/

2、用wget下载repo文件

输入命令wget  http://mirrors.aliyun.com/repo/Centos-7.repo

如果wget命令不生效，说明还没有安装wget工具，输入yum -y install wget 回车进行安装。

当前目录是/etc/yum.repos.d/，刚刚下载的Centos-7.repo也在这个目录上

3、备份系统原来的repo文件

mv  CentOs-Base.repo CentOs-Base.repo.bak

即是重命名 CentOs-Base.repo -> CentOs-Base.repo.bak

4、替换系统原理的repo文件

mv Centos-7.repo CentOs-Base.repo

即是重命名 Centos-7.repo -> CentOs-Base.repo

5、执行yum源更新命令

yum clean all

yum makecache

yum update

依次执行上述三条命令即配置完毕。

清理多余的内核
https://blog.csdn.net/microhhh/article/details/80243189

在使用

sudo yum update
命令更新centos的内核与库后，需要进行一些清理工作。

1.删除CentOS更新后的旧内核

首先查看系统当前内核版本

uname -a
提示如下

Linux localhost.localdomain 3.10.0-693.21.1.el7.x86_64 #1 SMP Wed Mar 7 19:03:37 UTC 2018 x86_64 x86_64 x86_64 GNU/Linux

红色部分为当前内核。

然后查看系统中全部的内核RPM包

rpm -qa | grep kernel
提示如下

kernel-tools-libs-3.10.0-693.21.1.el7.x86_64
abrt-addon-kerneloops-2.1.11-48.el7.centos.x86_64
kernel-3.10.0-693.21.1.el7.x86_64
kernel-tools-3.10.0-693.21.1.el7.x86_64

kernel-3.10.0-693.el7.x86_64

删除旧内核的RPM包，例如

sudo yum remove kernel-3.10.0-693.el7
重启系统

sudo reboot
注意:不需要手动修改/boot/grub/menu.lst
