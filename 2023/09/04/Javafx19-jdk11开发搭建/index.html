Javafx19-jdk11开发搭建

安装前置环境

1） jdk11 https://www.oracle.com/java/technologies/downloads/#java11-windows

下载jdk11后，安装配置环境变量。

2） Javafx19 https://gluonhq.com/products/javafx/

非maven模式，下载引入

maven模式：不需要安装，使用依赖引入 ；参考链接

3）graalvm https://github.com/graalvm/graalvm-ce-builds/releases

xcode从app store安装

下载 https://github.com/graalvm/graalvm-ce-builds/releases/download/vm-22.2.0/graalvm-ce-java11-darwin-aarch64-22.2.0.tar.gz

下载 https://github.com/graalvm/graalvm-ce-builds/releases/download/vm-22.2.0/native-image-installable-svm-java11-darwin-amd64-22.2.0.jar

解压graalvm-ce-java11-darwin-aarch64-22.2.0.tar.gz 到目录下 /Users/yhao521/storage/Environment/JavaFX/graalvm-ce-java11-22.2.0

配置 环境变量

  • 设置GraalVM环境变量（注意JAVA_HOME也要指向GRAALVM_HOME）：
  • 验证环境 java -version
  • 安装native-image组件(找不到gu，请到graalvm-ce-java11-22.2.0/Contents/Home/bin下执行)
  • 验证组件

如果您使用的是macOS Catalina及更高版本，您可能需要从位中删除隔离属性，然后才能使用它们
为此，请运行以下内容：

$ sudo xattr -r -d com.apple.quarantine path/to/graalvm/folder/

sudo xattr -r -d com.apple.quarantine /Users/yhao521/storage/Environment/JavaFX/graalvm-ce-java11-22.2.0

创建项目

mvn archetype:generate
-DarchetypeGroupId=org.openjfx
-DarchetypeArtifactId=javafx-archetype-fxml
-DarchetypeVersion=0.0.6
-DgroupId=org.openjfx
-DartifactId=javafx_test1
-Dversion=1.0.0
-Djavafx-version=11

或使用idea的maven原型创建

命令使用

插件javafx-maven-plugin

引入后，进行配置

mvn clean javafx:jlink

打包：成二进制文件，双击javafx_test3 的对应bin目录下的javafx_test3文件，可以运行；（会有控制台窗口）

mvn clean javafx:run

运行调试

插件gluonfx-maven-plugin

为了创建原生应用程序，GluonFX插件引入了以下目标：

  • gluonfx:run ：运行
  • gluonfx:runagent
  • gluonfx:compile ：编译
  • gluonfx:link ：链接
  • gluonfx:build 构建. 第一次，会下载需要的静态库等
  • gluonfx:package 打包为app
  • gluonfx:install
  • gluonfx:nativerun 本地方式运行
  • gluonfx:sharedlib 打包为库文件
