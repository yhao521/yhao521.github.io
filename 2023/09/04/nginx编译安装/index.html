nginx编译安装

[]: nginx.sh

[[_resources/4fd211c2eed24c20f48e08d12fe5ea95_MD5.sh|Open: nginx.sh]]
![[_resources/4fd211c2eed24c20f48e08d12fe5ea95_MD5.sh]]

前提： 安装编译环境，执行 yum -y install make zlib zlib-devel gcc-c++ libtool openssl openssl-devel pcre-devel

1.下载nginx http://nginx.org/download/nginx-1.22.0.tar.gz

2.上传到nginx.sh所在同级目录soft下

4.执行 sh app.sh stop_ui 停止

5.进入平台安装目录下，如果存在，清理已存在目录，执行 rm -r nginx && rm -r nginx-1.22.0

6.执行 sh app.sh start_ui ，编译和启动nginx
