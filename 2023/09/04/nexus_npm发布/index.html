把打包好的vue组件发布到私服

1.创建npm仓库2.发布组件

创建npm仓库

设置–>Repository–>Repositories–>Create repository

好了，现在我们把做好的vue组件发布试试！
先登录私服：
npm login –registry=http://172.18.231.119:9011/repository/npm_crds_web/
输入账号
输入密码
输入邮箱

第一次需要登录，下次发布组件就需要登录了

发布组件，终于到了这一步骤…

npm publish –registry=http://172.18.231.119:9011/repository/npm_crds_web/
很愉快的输入这一命令，

在package.json 中添加

npm publish

编辑“.npmrc”文件，增加或修改“registry”、“email”、“_auth”以及“always-auth”：
