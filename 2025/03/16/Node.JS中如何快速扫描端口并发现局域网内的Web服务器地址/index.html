Node.JS中如何快速扫描端口并发现局域网内的Web服务器地址

在 Node.JS 中进行端口扫描还是比较方便的，一般会有广播和轮询两种方式。即使用广播和扫描，使用广播发出的消息有时会被路由器屏蔽，所以并不可靠。

使用node.js中的net模块，可以直接尝试向目录主机的某个端口进行连接，如果能建立连接，则说明该地址存在服务器。
