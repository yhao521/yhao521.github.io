错误1：
转MP3错误情况；
ffmpeg: error while loading shared libraries: libmp3lame.so.0: cannot open shared object file: No such file or directory等类似的错误
解决办法是建立软链接：

ln -s /usr/local/lib/libmp3lame.so.0.0.0 /usr/lib64/libmp3lame.so.0

或者直接修改修改/etc/ld.so.conf
vi /etc/ld.so.conf
新增一行 /usr/local/lib

或者是在 /etc/ld.so.conf.d/目录下创建一个名为local-libraries.conf的文件
新增一行/usr/local/lib
原理一样~~
再执行ldconfig -v

错误2：
libtheora-1.1 Could not run Ogg test program, checking why…

明明安装了ogg但theora却认为咱们没安装。
原因是你的PKG_CONFIG_PATH路径没有指对
export PKG_CONFIG_PATH=/lib64/pkgconfig:/home/gongjia/external/ffmpeg.src/_release/lib/pkgconfig

ffmpeg -i input.mp4 -c:v libx265 -c:a copy output.mp4

brew install ffmpeg –with-fdk-aac –with-ffplay –with-freetype –with-libass –with-libquvi –with-libvorbis –with-libvpx –with-opus –with-x265

brew update && brew upgrade ffmpeg

brew install ffmpeg –HEAD
