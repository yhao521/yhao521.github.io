ffmpeg的安装方法

发表于2025-03-17|更新于2025-03-17|博客
|浏览量:

卸载之前的安装

  1. pip uninstall ffmpeg-python
  2. pip uninstall ffmpeg

然后再安装:

  1. conda install -c menpo ffmpeg
  2. pip install ffmpeg-python
