influxdb升级步骤

发表于2024-01-13|更新于2024-01-13|博客
|浏览量:

influxdb1.7.4 升级为influxdb1.8.0

1.停掉原有的influxdb

ps -ef| grep influxd | grep -v ‘grep’ | grep -v ‘proxy’ | awk ‘{print $2}’ | xargs kill -9

2.上传安装包，解压

tar -zxvf tsdb-influxdb1.8.0-e3base1.6.0.tgz
mv tsdb-influxdb1.8.0-e3base1.6.0 influxdb1.8.0
mkdir -p ./influxdb1.8.0/{data,logs}

3.修改配置文件中的下列对应参数

cd influxdb1.8.0/etc/influxdb. && vi influxdb.conf
[meta]
dir = “/paas/iddbs/crds_web/influxdb1.8.0/data/influxdb/meta”
logging-enabled = false
[data]
dir = “/paas/iddbs/crds_web/influxdb1.8.0/data/influxdb/data”
wal-dir = “/paas/iddbs/crds_web/influxdb1.8.0/data/influxdb/wal”
query-log-enabled = false
max-series-per-database =0
max-values-per-tag = 0
[http]
bind-address = “172.18.231.39:25001”
log-enabled = false

4.迁移数据目录(保留原始备份)

cd influxdb1.7.4
cp -r data ../influxdb1.8.0/

5.启动influxdb

nohup /paas/iddbs/crds_web/influxdb1.8.0/usr/bin/influxd -config /paas/iddbs/crds_web/influxdb1.8.0/etc/influxdb/influxdb.conf 2>&1 >> /paas/iddbs/crds_web/influxdb1.8.0/logs/influxdb.log &

5.登陆验证

/paas/iddbs/crds_web/influxdb1.8.0/usr/bin/influx -precision rfc3339 -host 172.18.231.39 -port 25001

6.如果之前有配置用户密码，登陆执行命令，创建用户（可选）

CREATE USER “promethues” WITH PASSWORD ‘promethues’ WITH ALL PRIVILEGES

7.如果之前有配置用户密码，请继续设置参数，开启验证，重新创建用户（可选）

[http]
auth-enabled = true

8.停掉、再启动influxdb（执行第1步、第4步的命令）（可选）

9.验证登陆，有账号的（可选）

/paas/iddbs/crds_web/influxdb1.8.0/usr/bin/influx -precision rfc3339 -host 172.18.231.39 -port 25001 -username ‘promethues’ -password ‘promethues’
