mysql5.7单实例安装

发表于2024-01-10|更新于2024-01-10|博客
|浏览量:

1.检查环境

  1. [root@lxd-vm1 data]# rpm -qa | grep mysql

  2. mysql-5.1.71-1.el6.x86_64

  3. mysql-libs-5.1.71-1.el6.x86_64

  4. qt-mysql-4.6.2-26.el6_4.x86_64

  5. mysql-devel-5.1.71-1.el6.x86_64

  6. mysql-server-5.1.71-1.el6.x86_64

  7. [root@lxd-vm1 data]#

发现当前环境中在操作系统安装阶段已经安装默认的5.1的mysql，建议删除掉，避免不必要的影响。

2.清理自带的mysql环境

  1. [root@lxd-vm1 data]# rpm -e mysql-5.1.71-1.el6.x86_64 –nodeps

  2. [root@lxd-vm1 data]# rpm -e mysql-libs-5.1.71-1.el6.x86_64 –nodeps

  3. [root@lxd-vm1 data]# rpm -e qt-mysql-4.6.2-26.el6_4.x86_64 –nodeps

  4. [root@lxd-vm1 data]# rpm -e mysql-devel-5.1.71-1.el6.x86_64 –nodeps

  5. [root@lxd-vm1 data]# rpm -e mysql-server-5.1.71-1.el6.x86_64 –nodeps

  6. [root@lxd-vm1 data]#

  7. [root@lxd-vm1 data]# rpm -qa | grep mysql | wc -l

  8. 0

  9. [root@lxd-vm1 data]#

3.创建组和用户

  1. [root@lxd-vm1 ~]# groupadd -g 700 mysql

  2. [root@lxd-vm1 ~]# useradd -g mysql -u 700 mysql

  3. [root@lxd-vm1 ~]# passwd mysql

  4. Changing password for user mysql.

  5. New password:

  6. BAD PASSWORD: it is too short

  7. BAD PASSWORD: is too simple

  8. Retype new password:

  9. passwd: all authentication tokens updated successfully.

  10. [root@lxd-vm1 ~]#

4.创建目录结构

  1. [root@lxd-vm1 ~]# cd /opt

  2. [root@lxd-vm1 opt]# mkdir mysql

  3. [root@lxd-vm1 opt]# mkdir -p /data/mysql

  4. [root@lxd-vm1 opt]# mkdir -p /data/mysql/mysql3306

  5. [root@lxd-vm1 opt]# mkdir -p /data/mysql/mysql3306/{data,logs,tmp,binlog}

  6. [root@lxd-vm1 opt]# chown -R mysql:mysql /data/mysql/mysql3306

5.上传软件并解压

  1. [root@lxd-vm1 mysql]# pwd

  2. /opt/mysql

  3. [root@lxd-vm1 mysql]# ll

  4. total 627632

  5. -rw-r–r– 1 root root 642694570 Aug 10 16:25 mysql-5.7.14-linux-glibc2.5-x86_64.tar.gz

  6. [root@lxd-vm1 mysql]# tar -zxvf mysql-5.7.14-linux-glibc2.5-x86_64.tar.gz

6.创建软链接

  1. [root@lxd-vm1 local]# pwd

  2. /usr/local

  3. [root@lxd-vm1 local]# ln -s /opt/mysql/mysql-5.7.14-linux-glibc2.5-x86_64 /usr/local/mysql

  4. [root@lxd-vm1 local]# ls -l mysql

  5. lrwxrwxrwx 1 root root 45 Aug 10 16:48 mysql -> /opt/mysql/mysql-5.7.14-linux-glibc2.5-x86_64

  6. [root@lxd-vm1 local]#

7.编辑参数文件

8.初始化数据库

  1. [root@lxd-vm1 ~]# /usr/local/mysql/bin/mysqld –defaults-file=/data/mysql/mysql3306/my3306.cnf –initialize

  2. [root@lxd-vm1 ~]# grep password /data/mysql/mysql3306/logs/error.log

  3. 2016-08-10T13:34:41.861545Z 1 [Note] A temporary password is generated for root@localhost: lKa!lSipc8hd

  4. [root@lxd-vm1 ~]#

注意从5.7开始

（1）初始化使用的是mysqld

（2）以不报错，什么都不提示，为正常，初始化完成后，生成随机的‘root‘@’localhost’的密码,输出到错误日志。

9.启动数据库

  1. [mysql@lxd-vm1 ~]$ /usr/local/mysql/bin/mysqld –defaults-file=/data/mysql/mysql3306/my3306.cnf &

  2. [1] 2431

  3. [mysql@lxd-vm1 ~]$ ps -ef | grep -w mysqld | grep -v grep

  4. mysql 2431 2372 0 21:44 pts/1 00:00:00 /usr/local/mysql/bin/mysqld –defaults-file=/data/mysql/mysql3306/my3306.cnf

  5. [mysql@lxd-vm1 ~]$

10.安装后首次登录数据库

  1. [mysql@lxd-vm1 ~]$ mysql -uroot -p -S /data/mysql/mysql3306/my3306.sock

11.注意8.8.8.%，并不包含localhost，如果创建了用户，在本地测试，还需要授权给localhost

12.查看进程

  1. [mysql@lxd-vm1 bin]$ ps -ef | grep -w mysqld | grep -v grep

  2. mysql 2184 1 0 10:24 ? 00:00:14 /usr/local/mysql/bin/mysqld –defaults-file=/data/mysql/mysql3306/my3306.cnf

  3. [mysql@lxd-vm1 bin]

13.查看端口

  1. [mysql@lxd-vm1 bin]$ netstat -nltp 2>/dev/null | grep 3306

  2. tcp 0 0 :::3306 :::* LISTEN 2184/mysqld

  3. [mysql@lxd-vm1 bin]$
