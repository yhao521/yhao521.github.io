mysql解压版安装

发表于2024-01-10|更新于2024-01-10|博客
|浏览量:

Windows中mysql5.7.16的解压版安装

1解压到E:/mysql/mysql5.7

新建，修改my.ini

2.进入管理员命令行：

并，切入mysql5.7安装目录

E:

Cd mysql/mysql5.7/bin

3执行命令：

安装服务：

Mysqld install

卸载服务

Mysqld remove

 4先初始化data目录

mysqld –initialize-insecure –user=mysql

文档表明，使用-initialize生成随机密码，由于自己学习，使用-initialize-insecure生成空密码。默认帐号root,后面的-user=mysql不更改

5在提示命令管理工具输入如下命令，进入安全模式：

mysqld –defaults-file=”E:\mysql\mysql5.7\my.ini” –console –skip-grant-tables，这里的路径需要根据你安装的实际路径修改。好的，这个窗口让它就这么运行，然后重新打开一个命令提示窗口，记得一定是管理员权限。

6接下来要修改root的默认密码。

前使用的数据库：输入use mysql；

6.1.进入mysql数据库：

mysql> use mysql;

Database changed

6.2.给root用户设置新密码

mysql> update user set authentication_string=password(“root”) where user=”root”;

Query OK,1 rows affected(0.01 sec)Rows matched:1 Changed:1Warnings: 0

6.3.刷新数据库 （一定要记得刷新）

mysql>flush privileges;

 QueryOK, 0 rows affected (0.00 sec)

6.4.退出mysql：

mysql> quit或mysql> \q

下次输入mysql -uroot -proot 就可以登录了

7.如果有data目录的备份可以省略第4步及以后，直接按照原有的用户登录。

8错误：

mysql启动后自动停止？：

初始化data目录时，出错：没有数据库（schema）mysql、performance_schema、sys等，导致启动错误。在

又由于在my.ini中多写了“ss”,导致初始化data失败。

default-storage-engine=INNODB ss

去掉后，就成功了。
