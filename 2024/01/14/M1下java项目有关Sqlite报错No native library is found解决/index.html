M1下java项目有关Sqlite报错No native library is found解决

发表于2024-01-14|更新于2024-01-14|博客
|浏览量:

背景

更换了M1芯片的macbook之后，将原来win上的java项目搬过来运行报错Exception: No native library is found for os.name=Mac and os.arch=aarch64

原因

项目中使用的老版本sqlite不支持arm架构

解决方案

在网上搜索的方案提及用新的sqlitejar包替换idea文件夹下Contents中的jar包，但在我这里并没有效果，后来尝试将pom中sqlite的版本设置为最新版本后完美运行
