Mac安装Oracle 19.3.0

发表于2024-05-06|更新于2024-05-07|博客
|浏览量:

目前学校在教数据库设计需要用到Oracle，但是Oracle不能直接安装在Mac上，按住了新买一台电脑的冲动，经过一个小时的研究，找到了个方法在Mac上运行Oracle以及与DataGrip相连，希望能帮助到大家。

在最开始我想先简单说说这个方法最大缺点 -> 需要占用大量电脑的储存空间，大概是55个G左右，如果能接受这个缺点就请往下看

  1. 首先用Docker安装Oracle需要两个文件

    • docker-images-master.zip (3.1MB)
      在 https://github.com/oracle/docker-images下载Oracle Docker build files.
    1. LINUX.X64_193000_db_home.zip (3.07GB)
      访问http://www.oracle.com/technetwork/database/enterprise-edition/downloads/index.html下载 (需要注册Oracle) ![在这里插入图片描述](/img/CleanShot 2024-05-07 at 09.45.13@2x.png)

  2. 解压docker-images-master.zip到桌面并依次打开docker-images-master -> OracleDatabase -> SingleInstance -> dockerfiles -> 19.3.0 文件夹

  3. 复制LINUX.X64_1919000_db_home.zip到19.3.0文件夹中

  4. 返回上一级文件夹dockerfiles 并在此文件夹运行终端执行


这一步需要下载到几个相关文件，如果报错多试即几遍即可，可能是因为网络问题导致的，下图是这一步完成时的截图

  1. 完成后在终端执行 (如果报错请在Docker Desktop查看容器是否开启)

    docker-compose.yml

    这一步是为了数据持久化到你的电脑中，以至于就算把容器删掉，Oracle上的数据还能保留在你的电脑上，其中这个路径/Users/daicongren/oradata:/opt/oracle/oradata oracle/database:19.3.0-ee 只需要修改daicongren为你自己的路径，其他保持不变

    最后到这里会停止，我等了大概十几分钟都没动过，我就退出了，也不影响使用

  2. 设置Oracle的密码用于连接DataGrip

    XXXXXX为你的密码

  3. 按如图所示连接DataGrip

  4. 如果以后不需要再安装Oracle的话，可以删除桌面上用完的docker-images-master文件夹 (可选)

至此整个安装结束
