老外都眼馋的中文提示词插件 ComfyUI 版

发表于2024-05-23|更新于2024-05-23|博客
|浏览量:

不知道小伙伴们还记不记得，之前听雨分享过一个老外都眼馋的 SD 中文提示词插件：oldsix，用过的小伙伴应该都不陌生吧，是不是挺好用的。

不过那个是 webUI 版的，现在有很多小伙伴已经开始尝试 ComfyUI 了。

如果在 ComfyUI 中也能使用就好了，嗯，现在还真可以在 ComfyUI 中使用了，还是同一个作者，整体的界面也差不多。

今天听雨就来分享下！

闲话不多说，我们直接开整！

安装就不多说了，直接通过 ComfyUI 管理器中 Git URL 安装，安装完成以后重启 ComfyUI。

安装地址：https://github.com/thisjam/comfyui-sixgod_prompt

重启完成以后，我们加载默认的文生图工作流即可，然后删除原始的 CLIP 文本编码器。

在空白的地方双击，然后搜索 six，选中就可以得到插件专属的文本输入框了。

创建两个，一个填正面提示词，一个填反面提示词。

节点创建完以后，用快捷键「Alt+Q」打开插件界面。

用过 oldsix 插件的小伙伴看这个界面是不是挺眼熟的！

进入界面以后需要先点击左上角的「同步数据」按钮，点击确定即可。

然后我们先选一些正向和反向提示词，依旧是左键选中对应提示词自动输入正向提示词框，右键选中对应提示词自动输入反向提示词框。

正向提示词选中是绿色，反向提示词选中是红色。

不如选中的提示词不想要了，再重新点击选中的提示词即可，依旧是左键对应正向，右键对应反向。

然后我们继续点击快捷键「Alt+Q」回到我们的工作流界面。

可以看到我们选中的提示词已经自动填入文本框中。

之所以想让小伙伴们试一下，不着急连线是因为这两个文本框一模一样，不知道哪个是输入正向提示词，哪个是输入反向提示词的。

现在就清楚了。

我们直接来连线，按照下图连接就可以了，用「SixGodPrompts」节点替换「CLIP 文本编码器」节点。

或者我们也可以一开始就连好，虽然我们不知道哪个是正，哪个是反。

如果节点连反了，那就点击左上角这个「交换正反同步」也行，记得需要再点下「同步数据」。

顺便也说下旁边的「设置」按钮，主要是用来配置翻译 API 接口，当然我们也可以直接默认免费的。

是的，插件的输入框是支持中英文双语的，所以我们可以直接输入中文，中英文混用都可以。

快捷键就是用来设置唤起提示词界面的快捷键，不想用「Alt+Q」也可以换一个。

继续回到我们的工作流，我们在插件界面选中对应提示词同步以后，我们还可以在输入框再输入提示词，可以直接用中文输入哦！

我们再回到插件页面，鼠标移动到下图红框的位置可以发现出来了正负两个符号，点击可以用来增加或者减少权重。

左键点击红框中的关键词则可以从文本框禁用对应的提示词，右键点击则可以删除当前提示词，还可以双击对提示词进行编辑。

还可以拖动来交换位置。

当然，我们也可以直接在文本框中手动进行删除或者编辑。

我们继续来看下「自定义随机词库」功能，我们可以直接选中大类，比如直接选中「人设」，人设相关的提示词都会自动填入随机词库中，我们也可以单独选择想要的提示词。

点击「发送到正向提示词框」。

就会自动生成动态语法，每次都会随机取不同的提示词生成图片，可以设置多个动态随机词库。

听雨这边加了人物和服饰的动态随机词库，看下随机生成的图片。

好了，我们继续来看「收藏夹」功能，点击收藏夹可以收藏当前的提示词。

导：把收藏的提示词导入提示词框。

排：排序，数值越大，越靠前。

删：顾名思义，删除当前收藏的提示词。

最后一个「随机灵感」功能就是随机生成提示词啦！

听雨用随机提示词生成的图片，这个在我们没有想法的时候可以试试，嗯，有想法的时候也可以试，有惊喜哦！

还有一个功能不在界面上，如果插件的提示词库不能满足我们，我们也可以自定义提示词库。

进入插件目录的「yours」目录下，创建一个 json 文件即可。

文件中输入我们自定义的提示词，格式可以参照「json」目录下的文件的提示词格式。

好了，今天的分享就到这里了，感兴趣的小伙伴快去试试吧！
