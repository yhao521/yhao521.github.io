MacBook M1 编译Android项目报错 Exception_ No native library is found for os.name=Mac and os.arch=aarch64

发表于2024-05-25|更新于2024-05-25|博客
|浏览量:

今天M1Pro芯片的MacBook Pro到手了，激动得想试试编译有多快，但是编译公司Android项目的时候，却出现了这个报错。

查了资料才知道，是苹果的M1芯片和Room有兼容性问题。

详见https://developer.android.google.cn/jetpack/androidx/releases/room#2.4.0-alpha03

所以，我们把room的版本升级到2.4.0-alpha03即可解决这个问题

记得要使用最新版本的Android Studio，并使用java 11进行编译，否则使用room-runtime:2.4.0，编译会报其他错误的

再次运行程序，可以看到程序运行成功了 !

详见 Caused by: java.lang.Exception: No native library is found for os.name=Mac and os.arch=aarch64. path=/org/sqlite/native/Mac/aarch64
